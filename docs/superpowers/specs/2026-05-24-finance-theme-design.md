# Finance Theme — Design Spec

Add two MarkText themes based on Terance Jiang brand: finance-light (warm paper) and finance-dark (cool slate).

## Files

1. `src/renderer/src/assets/themes/finance-light.theme.css` — new
2. `src/renderer/src/assets/themes/finance-dark.theme.css` — new
3. `src/renderer/src/util/themeColor.ts` — import + addThemeStyle switch cases
4. `src/main/menu/templates/theme.ts` — menu items
5. `static/locales/en.json` — label
6. `static/locales/zh-CN.json` — label

## Colors

Light: paper #fafaf7, ink #1c1c1a, steel-blue #2563a0 accent
Dark: slate #161614, warm-white #e8e7e0, sky-blue #5a9fd4 accent
