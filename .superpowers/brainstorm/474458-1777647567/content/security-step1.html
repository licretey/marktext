唯一需要修改的代码

文件 改动 原因
src/main/config.js (2处) false → true 核心安全开关
fontTextBox/index.vue require('font-list') → IPC 渲染进程唯一的运行时 require()
src/main/windows/ IPC handler 注册 暴露 getSystemFonts 给渲染进程

为什么这步可以独立做

  • Preload 已有 process.contextIsolated 条件分支，设 true 后自动走 contextBridge 路径
  • 所有 ~20 个渲染进程文件使用 window.electron / window.fileUtils 等 API，contextBridge 注入后访问方式不变
  • Muya 的 require() 调用在 vite 构建阶段已被打包转换，非运行时调用
  • nodeIntegration: true 暂保留意味着 preload 可继续使用 Node API
